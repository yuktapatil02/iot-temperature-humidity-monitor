IoT Based Temperature & Humidity Monitoring System

This project is an IoT-based Temperature and Humidity Monitoring System developed using ESP8266 and DHT11/DHT22 sensor. The system measures real-time environmental temperature and humidity data and uploads it to the ThingSpeak cloud platform through Wi-Fi connectivity.

The project enables remote monitoring of environmental conditions using graphs and live data visualization. It demonstrates the practical implementation of IoT, sensor interfacing, cloud integration, and wireless communication.

Features
Real-time temperature and humidity monitoring
Wi-Fi enabled IoT system using ESP8266
Cloud data storage using ThingSpeak
Live graphical data visualization
Low-cost and efficient monitoring solution

Components Used
ESP8266 NodeMCU
DHT11/DHT22 Sensor
Jumper Wires
Breadboard
ThingSpeak Cloud Platform

Applications
Smart homes
Weather monitoring systems
Industrial environment monitoring
Agriculture and greenhouse monitoring

Technologies Used
Embedded C / Arduino IDE
IoT
Wi-Fi Communication
ThingSpeak Cloud Integration
